# User Study 交接说明（供写作 Session）

> **用途**：把本项目的小规模 user study 的最终设计、目标、正向判定与诚实边界交给论文写作 Session。写作时**只以此为准**；本研究处于 `DRAFT / 尚未招募 / 尚无人类数据` 状态，任何结论都不得写成"已获得的实证结果"。
>
> **对齐到最新论文（2026-08 reframe 后）**：论文标题为 *Before You Add the Slider: A Comparator-Bound Test for Latent Controls in LLM Interfaces*。**新版论文刻意不使用一套固定的"四态 taxonomy"**，而用"**界面动作 + 阻断原因（interface action + blocking reason）**"语言。本 study 的判定内核、正确答案、A/B 配对、GAA、诚实边界**均不变**；只是四个面向用户的"去处"要**映射**到新版语言（见 §2）。
>
> **一句话**：这是一个**面向普通非技术用户、生活化、零术语**的小规模（**N ≈ 20**）within-subject 理解性 micro-study，检验"论文的对照约束门槛（comparator-bound test）是否可被普通人理解并正确应用"——**不**检验用户收益、信任或界面优越性。

---

## 1. 它服务于论文的哪个贡献

论文的核心主张：一个界面上的"控制"（标着某属性的滑块/按钮/旋钮）**不应仅因为"能改变输出"就被当作可调的 active control**。要成为可调 active control，必须证明它**赢过一个有界的 prompt 对照（bounded prompt comparator，从预注册候选里 DEV 选出）**，并满足 **point-estimate floor（δ=0.05）、CI 排零、coherence**；否则只能是 **read-only diagnostic candidate（仅可读检视）/ active control withheld（带明确 blocking reason）**。

> 新版论文用"界面动作 + 阻断原因"而非固定四态。可能的 **blocking reason**：`interval includes zero`（CI 含零）/ `comparator-negative`（不优于对照）/ `below floor`（点估不达 δ）/ `coherence fails`（连贯性失败）/ `missingness-limited`（缺失/欠功效受限）。

**本 user study 只回答一个问题**：普通非技术用户在被**简短教学**后，能否**正确地把这套对照约束门槛应用到具体案例**——即该门槛是否"对人可理解、可操作"，而非只有专家能用。

它对应论文的**方法论/评估贡献**的一个**可理解性佐证**，属 formative（探索性）证据，不是核心实证结论。

## 2. 任务设计（最终方案）

**参与者角色**：普通用户，整理"自己家里/手机上的按钮板"。不扮演评审员或工程师，不需要任何 AI/统计背景。

**呈现**：全程**生活化、零术语、零歧义措辞**（不出现任何机器学习/统计名词，也不用会被误读的模糊词）。所有材料均为**明确标注的虚构/示意试用记录**，不代表任何真实产品功效。

**交互（开卷 + 一步一问）**：
- 屏幕上**始终显示**：当前案例的"虚构试用记录"、"你原来怎么做"、四个去处说明、以及判断用的问题清单——**参与者无需记忆任何概念**（recognition，不是 recall）。
- 每个案例**一次只回答一个"看着记录就能答"的小问题**，系统据回答**自动推出**该放进哪个去处，并显示推理路径。参与者可**回退到任意已答步骤重新选**。

**四个面向用户的"去处" → 新版论文语言的映射**
（这 4 个桶是**对普通用户友好的去处**，教学上有用；它们**不是**论文的"官方状态名"，写作时请用右两列的动作/原因语言。每题的"冻结正确答案"均按新版门槛逻辑计算，且已逐题核对与旧版一致。）

| 参与者看到的去处 | 新版论文对应（interface action） | 判定 / blocking reason |
|---|---|---|
| 常用区（须写清"仅在…"范围） | **active control passes the gate**（限已测 tier） | 赢过 bounded prompt 对照 + 点估 ≥ δ + CI 排零 + coherence 过 |
| 信息牌 | **read-only diagnostic candidate** | 只能显示状态、不当作 active control（READ 支持、非已验证诊断） |
| 不装 | **active control withheld**（证据足够说不） | reason = `comparator-negative`（不优于/更差）或 `coherence fails`（弄坏别的） |
| 再看看 | **active control withheld**（证据不足） | reason = 未做对照 / 范围没写清 / 欠功效 / `interval includes zero` |

> 注意：新版里"不装"和"再看看"其实是**同一个界面动作 `active control withheld`**，只是 blocking reason 不同（证据足够说不 vs 证据不足）。study 保留 4 个用户友好桶，但正文/映射请落到"动作 + 原因"。

**判定链（每案例，逐步、遇到即结束；与新版门槛逻辑一致）**：
1. 这是"看情况"还是"按一下改变结果"？→ 看情况 → **信息牌 = read-only diagnostic candidate**
2. 有没有和**你原来的简单做法**（新版对照 = bounded prompt comparator 的生活化类比）在相同条件下**放一起比过**？→ 没有 → **再看看 = withheld（证据不足：未做对照）**
3. 比下来**赢过原来的做法**，还是**差不多/更差**？→ 差不多/更差 → **不装 = withheld（comparator-negative）**
4. 有没有把**别的重要事情弄坏**？→ 有 → **不装 = withheld（coherence fails）**
5. 有没有写清**只在哪些情况试过**？→ 没写清 → **再看看 = withheld（证据不足：范围/缺失受限）**
6. 从若干"仅在…"里**选对范围** → **常用区 = active control passes the gate（限该 tier）**

**核心可迁移直觉（零术语教会，与新版论文一致）**：按钮"有反应/东西变了" ≠ 它比你原来的做法更好；**要赢的是你已有的简单做法（对应有界 prompt 对照），不是赢"什么都不做"**；证据不足就搁置；只在试过的情况下才算数；"能显示状态" ≠ "能控制结果"。

**关键构念控制**：
- **A/B 配对**：一对案例**表面变化相同、其它条件全同**，唯一差别是"是否赢过原来的做法"——一个应进"常用区（passes the gate）"、另一个应进"不装（comparator-negative）"。这是最有力的检验：证明参与者是按证据门槛判断，而非只看表面变化。每位参与者只见其中一版（互斥）。
- 每案例证据只呈现**中性原始记录**（次数/场合/现象），由参与者自己推断，不直接给结论。
- 含 1 道注意检查题（非计分，用于剔除乱答）。

**规模**：small formative，**N ≈ 20**，within-subject（单会话，每人若干正式案例 + 1 练习 + 1 注意检查）。双语（简体中文 / English）。

## 3. 主要与次要指标

- **主指标 GAA（Gate Application Accuracy）**：每个正式案例，参与者最终选择的去处与**预先冻结的正确去处**一致即得 1 分；GAA = 正确案例比例。
- **严格版 Strict GAA**：不仅去处对，还要在判定链上**选对"决定性的那一步/正确的范围标签"**——用于排除"蒙对"。
- **次要（仅描述性）**：四态混淆、每步读卡正确率、A/B 配对辨别、完成/部分完成率、反应时间（仅描述）、注意检查通过率。

---

## 4. 什么样的参与者行为构成"正向"

按重要性：

1. **主结果**：GAA（及 Strict GAA）**显著高于随机基线**（四选一随机 = 25%；正向应远高于此，具体通过线在预注册时设定）。
2. **关键区分行为**（证明真在应用门槛，而非凭常识或表面）：
   - **A/B 配对**：在"赢过"那题选"常用区"、在"没赢过"那题选"不装"（最强正向信号）；
   - **诊断题**：证据只说明"能显示、不能改变结果"时选"信息牌"；
   - **范围/证据不足题**：稳定赢但范围没写清、或根本没做对照比较时，正确选"再看看"；
   - 注意检查通过。
3. **反向/失败信号**（需预先想好如何解释）：正确率接近随机 → 门槛对普通人不可自解释（可能是文案/教学/案例问题，**不得**直接归因"用户能力不足"）；系统性偏差（一律"不装"=过度保守 / 一律"常用区"=只看有反应）→ 某条直觉未传达；A/B 两题给相同答案 → 未在用门槛、只看表面变化。

## 5. 诚实边界（写作时的硬约束）

即使参与者全部做对，本研究**最多**可诚实写成：

> 在生活化、零术语的 within-subject 任务中，非技术参与者能以**高于随机**的准确率，把"改变≠更好、要胜过已有做法、证据不足则搁置、范围外不推广、能显示≠能控制"这套证据门槛应用到具体案例。

**不可写 / 不可暗示**（超出本研究范围）：
- 用了这套门槛会让用户**决策更好/更校准**；
- 控制台/界面**有用、被采用、提升信任/效率/满意度/掌控感**；
- 任何真实产品、写作助手或旋钮**真的有效**；
- 参与者对**虚构案例**的正确分类等同于现实中的正确使用；
- 验证了任何模型内部机制或因果；
- 本研究采用的证据量就是"正确上线标准"；
- 把本研究结果与论文的模型实验证据**混为一谈或合并**。

材料为**模拟/示意**，须在论文方法部明确声明；不得把卡片中的"试用结果"写成产品或机制的实证。

## 7. 一段可直接用于论文的中性描述（草案，供写作 Session 改写）

> 我们设计了一项小规模（N ≈ 20）、面向非技术用户的 within-subject 理解性研究，检验所提出的对照约束门槛（comparator-bound test）是否可被普通人理解并应用。参与者在生活化、零术语的情境中，对一系列明确标注为模拟的"试用记录"逐案例判断某个候选控制应对应哪种界面动作：作为通过门槛的可调控制（active control passes the gate，限已测 tier）、仅作只读诊断候选（read-only diagnostic candidate）、还是暂不提供（active control withheld，并区分"证据足够说不"与"证据不足"两类 blocking reason）。判定与"赢过一个有界的 prompt 对照、点估达到 δ、CI 排零、coherence"一致（在任务中类比为"赢过你已有的简单做法，而非赢'什么都不做'"）。主要指标为门槛应用准确率（与预注册的正确判定一致），并通过一对表面变化相同、仅"是否优于既有简单做法"不同的配对案例，检验参与者是否依据证据门槛而非表面变化作出判断。该研究评估门槛的可理解性与可应用性，**不**评估用户收益、信任或界面优越性。

> 术语提示：正文请使用新版"界面动作 + 阻断原因"语言，避免把本 study 面向用户的四个"去处"写成论文的固定四态 taxonomy。
