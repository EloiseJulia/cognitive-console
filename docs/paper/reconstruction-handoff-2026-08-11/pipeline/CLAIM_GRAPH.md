# Provisional Claim Graph

All evidence references are provisional assertions from `overview-zh.md`, not independently verified artifacts.

## Provisional One-Sentence Claim

For latent-control interfaces, a legible axis should pass an active-control computational gate only when, within a declared model-method-task scope, it demonstrates coherent outcome improvement over a bounded prompt comparator; the current 7–8B CAA/ITI application supplies scoped no-pass results with distinct blocking reasons, not a general verdict on latent steering.
