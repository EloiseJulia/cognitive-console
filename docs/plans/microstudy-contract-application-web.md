# Implementation Plan: Local Contract-Application Micro-Study

- **Plan ID:** `microstudy-contract-application-web`
- **Status:** executable materials finalized; web implementation pending fresh hostile audit
- **Current scope:** JSON materials, validator, tests, and documentation only
- **Spec:** [`../specs/microstudy-contract-application.md`](../specs/microstudy-contract-application.md)

## 1. Current revision

This revision creates the only authoritative future-web inputs:

```text
data/microstudy_contract_application/stimuli.json
data/microstudy_contract_application/sequences.json
```

It also adds:

```text
src/cognitive_console/microstudy_materials.py
scripts/validate_microstudy_materials.py
tests/test_microstudy_materials.py
```

The validator owns router derivation, sequence generation checks, parity, template reuse, key variation, lexical/token heuristics, oracle/LOO/global baselines, single-row Q1, and combined CCA. Markdown is not parsed and is not a second materials source.

No web app, recruitment, pilot, or participant data is included.

## 2. Future implementation rule

The future loopback website must consume the two JSON files directly. It may cache parsed records in memory but must not embed another copy of stimuli, templates, answers, tutorial/practice, sequences, diagnostic, ease options, or export fields. Q1 keys must be generated by the router and checked against JSON expectations; Q2 keys come from the validated assignment records.

Planned future package:

```text
src/cognitive_console/microstudy/
  server.py
  schema.py
  sequencing.py
  allocation.py
  scoring.py
  export.py
  analysis.py
  simulation.py
  static/
```

## 3. Future slices

### Rendering and flow

- Render Contract/Flat from one proposition map.
- Lock Q1 before Q2 and prohibit navigation back.
- Preserve exact common text and fixed geometry.
- Add DOM, screen-reader, keyboard, no-scroll, and declared-permutation screenshot checks.

### Allocation and export

- Use exact validated `A1..D5` rows.
- Generate a local random UUID attempt ID.
- Preserve ten planned slots and all truth-table states.
- Export only fields from JSON schema.
- Keep post-task diagnostic and block ease nullable/descriptive.
- Implement no attention check and no free-text controls.

### Analysis

- Rebuild keys, completion, eligibility, exclusions, CCA, missingness, bootstrap, and sign flips from raw export plus the frozen owner list.
- Add the separately audited MDE simulation before protocol freeze.

### Privacy

- Loopback only, no access logging, persistence, remote requests, timestamps, IP, UA, headers, demographics, or fingerprints.
