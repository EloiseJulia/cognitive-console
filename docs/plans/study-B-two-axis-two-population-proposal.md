## 1. 研究动机与中心论点（对齐新叙事）

一个 latent slider「好不好」是**人群相对**的，沿两条不同的轴评价，二者不可互相替代：

- **便利轴（convenience）**：对**写不出强 prompt 的用户**而言，滑块相对其真实备选（≈ average prompt）省力、易用。
- **有保证的增量控制轴（warranted control）**：对**能写出强 prompt 的用户**而言，问题是滑块是否真的**赢过**其真实备选（≈ best prompt）。

两个对照臂正是这两类人群真实备选的操作化：
- **average-prompt 对照** ↔ 非熟练用户的真实备选。
- **best-prompt 对照** ↔ 熟练用户的真实备选。

> 采用 B **意味着论文口径要改**：原来的「benefit 未测 / quality-only gate」caveat 不能再照旧写——B 显式（计划）测量便利与增量控制评价。论文需改成「便利/增量控制评价为 **planned/proposed**（study pending，无数据）」。此改动影响 Related Work / Framework / Implications / Limitations，需与并行的写作 session 对齐（见 §9）。

## 2. 人群划分：按 AI 熟练度**客观**判定（非自报专家/普通人）

owner 要求：**不让参与者自报「专家/普通人」**，而以「是否 AI 熟练使用者」判定。

**主判据（行为化，首选）—— prompt 能力探针：**
给参与者一个标准化任务，要求他们**自己写一条 prompt** 去达成某目标；对该 prompt 按**预注册 rubric** 客观评分（可用冻结评分标准 + 可选盲评双人一致性）。
- 这直接把人群划分锚定到叙事内核：**能否自己产出接近 best-prompt 的指令**。
- 熟练层 ≈ prompt 能力接近 best-prompt 臂；非熟练层 ≈ 接近 average-prompt 臂。

**辅助协变量（记录但不单独定层）：** LLM 使用频率、是否用过系统/参数设置、职业背景等——仅作稳健性/描述统计。

**开放决策（待 owner 定，§8）：** 探针任务与 rubric 具体形式、分层阈值（中位数切分？预设 cutoff？连续分 + 交互项？）、是否需要双盲评分。

## 3. 设计概览

- **样本：** 10 熟练 + 10 非熟练（owner 指定），小规模、探索性。
- **结构：** 混合设计——人群（熟练/非熟练，between）× 备选对照（average/best，within 或 between，待定）。
- **每位参与者流程（草案）：**
  1. 知情同意（双语，占位符待导师/伦理定稿）。
  2. **Prompt 能力探针**（→ 人群分层，客观评分）。
  3. 体验 latent slider 完成若干目标任务。
  4. 面对其**真实备选**（写自己的 prompt / 或给定 average/best 对照产物）完成同类任务。
  5. **两轴测量**（见 §4）。
  6. 可选：嵌入 **V3 门槛可应用性模块**（point 8 诊断，逻辑指纹不变）。
  7. 结构化反思 + debrief。

## 4. 测量项（两轴，均中性、不预设方向）

**便利轴：**
- 客观省力：完成时间、操作步数、修改次数。
- 主观易用/费力：简版 NASA-TLX 子量表或等价 Likert。
- 备选偏好：在「用滑块」vs「自己写 prompt / 用给定对照」间的选择与理由。

**有保证的增量控制轴：**
- 客观：滑块产物 vs 参与者真实备选产物在**同一 quality 指标**上的差（沿用论文对象层 metric 或用户可完成的任务表现）。
- 主观：参与者判断滑块是否「比我能给的指令更好」。

> **判分/正确答案边界：** 与 V3 一致——任何「正确答案 / 门槛判定」都只在 owner 端离线判分，**不进参与者端 payload/DOM/ARIA/export**。B 若嵌入 V3 门槛模块，沿用其"导出不含答案"契约与离线判分脚本。

## 5. 假设（中性、可证伪、无预设方向）

所有假设以**双侧、可被否证**的形式预注册；MDE 在协议冻结时设定。**不写入方向性预期**（避免 confirmation bias / HARKing）。示例（占位，待定稿）：

- **H1（人群 × 对照交互）：** 「滑块被判为赢过真实备选」的比率是否随 AI 熟练度分层与对照臂（average/best）而**不同**（H0：无交互）。
- **H2（便利轴）：** 便利/费力评价是否随熟练度分层**不同**（H0：无差异）。
- **H3（增量控制轴）：** 滑块相对真实备选的客观 quality 差是否随对照臂**不同**（H0：无差异 / 差为零）。
- **H4（可应用性，若嵌 V3 模块）：** 两人群应用对照约束门槛的正确率是否**不同**（H0：无差异）。

> owner 之前口述的「专家因不满足XX觉得不好用、普通人觉得方便但写不出好 prompt」**仅作可能情形之一**，绝不写死为待证实结论；结果向任何方向开放。
