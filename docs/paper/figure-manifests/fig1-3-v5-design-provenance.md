# Provenance — Manuscript Figures 1–3 (v5 hand-designed)

Figures 1–3 in `main.tex` are **hand-authored vector figures** (design revision
"v5"), not script-generated plots. They are therefore not covered by an
`aggregation_script` manifest. This document records their type, data source,
and the verification performed so their lineage is auditable.

- **Design source:** authored by the owner in a slide deck (`HCI-figures*.pptx`)
  and exported to vector PDF. The source `.pptx`/`.PNG` files are owner-held and
  intentionally **untracked** (not committed, per owner instruction); only the

- **manual_edits_allowed:** true (hand-designed). If any underlying number
  changes, these figures must be **re-verified by hand** against the source
  artifacts below.
